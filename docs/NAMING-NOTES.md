# Identidad de Acta

**SELECTED NAME: Acta**

**Questions. Evidence. Decisions.**

Acta es una plataforma open source para convertir preguntas estructuradas, conocimiento del equipo y evidencia en decisiones documentadas y trazables. Autor y titular: Cristóbal Ruz Escobar. Licencia: [AGPL-3.0-only](../LICENSE).

El nombre fue seleccionado por ser corto, pronunciable en español, neutral respecto al dominio y relacionado con decisiones documentadas. No limita el producto a requirements o a un sector. El descriptor permite comunicar su alcance internacionalmente.

La identidad visual aprobada se conserva. Se utiliza el wordmark **Acta**; no hay un logo formal o favicon propio verificado en este snapshot. **LOGO DESIGN — optional future work.** La falta de un logo no bloquea la preparación del snapshot. APP_LOGO y APP_FAVICON siguen disponibles para assets autorizados de cada instalación.

No se investigaron dominios ni marcas. La decisión de nombre no constituye una investigación de marcas. Titularidad y licencia de Acta fueron confirmadas por el titular el 2026-10-01; los avisos de terceros se conservan.
