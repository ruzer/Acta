# Plantillas del piloto

Copia cada tabla a una hoja de cálculo privada. Usa códigos P01, P02… en vez de
nombres. No registres contraseñas, enlaces privados ni contenido sensible. Una fila
por tarea o incidente; los campos vacíos no significan éxito. Fecha y hora local
con zona horaria acordada. Conserva comentarios literales, sin corregirlos.

| INC-01 | | | | | | | Abierto | | | |

**Crítico:** pérdida de datos, imposibilidad de entrar o información vista por
quien no debía. Pausa la tarea y avisa de inmediato; no esperes a confirmar una
fuga para proteger la información. **Alto:** impide una tarea principal pero se
puede trabajar con seguridad en otra. **Menor:** duda o dificultad sin impedir
la tarea. Estados: abierto, en revisión, pendiente de comprobar, cerrado. Solo
cierra tras comprobar el resultado y anotar quién lo verificó. No copies el dato
expuesto; describe su tipo y el alcance mínimo necesario.
