# Guía de Participante

Necesitas la dirección de Acta, tu usuario, contraseña temporal y un archivo de
prueba autorizado. No uses información sensible. Si entras por invitación, usa
[la guía de invitaciones](../EXTERNAL-INVITATIONS.md).

1. Abre la dirección recibida. Escribe **Usuario** y **Contraseña**; pulsa **Iniciar sesión**. No compartas tu acceso.
2. En **Cambia tu contraseña temporal**, llena **Contraseña actual**, **Nueva contraseña** y **Repetir nueva contraseña**. Pulsa **Actualizar contraseña**. Vuelve a **Iniciar sesión** con la nueva contraseña.
3. Al entrar verás **Mi trabajo**. Pulsa el nombre del proyecto y **Responder** junto a una pregunta. Lee la pregunta y su ayuda. Responde con lo que sabes; no inventes información.
4. Acta guarda el borrador al hacer una pausa. Espera el aviso de guardado; todavía no lo envías. Para continuar después, pulsa **Guardar y salir**. Si recargas con texto pendiente, elige **Restaurar texto de esta pestaña**. Usa **Continuar** para retomar.
5. Si necesitas un comprobante, abre **Adjuntar evidencia**, usa **Seleccionar evidencia** y pulsa **Adjuntar al borrador**. Espera **Evidencia adjunta al borrador. Todavía no se ha enviado.** Revisa el nombre del archivo.
6. Cuando termines, pulsa **Enviar respuesta**. Busca el aviso **Respuesta enviada**; Acta puede abrir la siguiente pregunta. Cada una se envía por separado.
7. Vuelve a **Mi trabajo** para ver pendientes. Si recibes una aclaración, abre la pregunta, completa **Tu aclaración** y pulsa **Enviar aclaración**. Busca el aviso **Aclaración enviada**; puede abrirse otra pregunta.
8. Al terminar, abre el menú de tu cuenta y pulsa **Cerrar sesión**, sobre todo si compartes la computadora.

## Si algo no funciona

- **No fue posible iniciar sesión con esos datos.** Revisa usuario y contraseña; si sigue ocurriendo, pide ayuda a quien te dio acceso. No mandes tu contraseña por chat.
- **No se pudo guardar. Tu texto sigue aquí**: conserva tu texto de forma privada, anota la hora y avisa al coordinador. No cierres la página creyendo que quedó guardado.
- Si no ves el proyecto o la pregunta, pide que revisen tu acceso y asignación. No uses la cuenta de otra persona.
