## Para preguntar sin exponer información

No publiques contraseñas, enlaces privados de invitación, respuestas, archivos
institucionales ni capturas con datos personales. Explica qué intentabas hacer,
la versión de Acta y el mensaje, usando datos inventados. Para fallas de tu acceso
local, avisa primero a la administración de tu institución. Las dudas generales
pueden ir a Discussions; su categoría aparece como Q&A. La atención es comunitaria,
sin plazo garantizado. Una respuesta comprobada puede incorporarse aquí mediante
[una propuesta de cambio](../../CONTRIBUTING.md#cómo-agregar-una-respuesta-a-la-ayuda).

¿No encontraste tu duda? [Pregúntala en Discussions (Preguntas y respuestas)](https://github.com/ruzer/Acta/discussions/categories/q-a).
